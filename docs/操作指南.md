## 1. 工作站是什么：核心概念

### 1.1 三层结构

```
 你 ─┬─ AI 助手（Claude Code / Codex …）——检索、AI 筛选、AI 精读
     └─ 图形化论文库（浏览器 http://127.0.0.1:8765）——浏览、分组、阅读、笔记、关联
                 │  两者读写同一个“个人文献库”
     ┌───────────▼──────────────┐
     │ 个人文献库 library/        │  你检索命中、挑选过的论文（越用越全）
     └───────────▲──────────────┘
                 │  检索命中 / 手动加入
     ┌───────────┴──────────────────────────────────────────┐
     │ 目录层：本地 dblp（884 万篇，离线，0.2 秒）               │
     │        + 在线源补“dblp 还没收录的新论文”                 │
     │          OpenAlex · Crossref · OpenReview · arXiv · Springer │
     └──────────────────────────────────────────────────────┘
```

- **目录 ≠ 文献库**：目录里是全世界的论文（只有基本信息）；文献库里只放你关心的论文，这些才需要摘要、PDF、笔记。
- **dblp 只用本地数据包**：dblp 网站会对自动访问弹人机验证，所以工作站从不在线访问 dblp。

### 1.2 你会经常看到的标记

| 标记 | 含义 |
|---|---|
| **T1 / T2 / T3** | 出处层级（你在 `config/venues.yaml` 里定义）。T1 = 最优先。`—` = 非优先出处 |
| **Y1 / Y2 / Y3** | 年份档：Y1 = 2024 年及以后，Y2 = 2021–2023，Y3 = 2021 年以前 |
| **L0 / L1 / L2 / L3** | 补全等级：L0 只有目录信息 · L1 有摘要 · L2 有本地 PDF · L3 有 AI 分析或你的笔记 |
| 待读 / 在读 / 已读 / 已排除 | 你的阅读状态（“已排除”的论文默认不在列表中显示） |
| ★ | 星标（重点论文） |
| 已录用 | OpenReview 上正式录用，但会议论文集还没出版 |
| 审稿中 | OpenReview 上的在审投稿（仅在明确要求时才会检索） |
| arXiv 声明录用 | 作者在 arXiv 备注里写“Accepted to XXX”，**未经官方核实** |
| 预印本 | 只有 arXiv 版本 |

### 1.3 排序规则：“优先”而不是“只要”

检索结果先按 **出处层级**（T1 → T2 → T3 → 其他），再按 **年份档**（Y1 → Y2 → Y3），最后按相关度排序。
年份优先是“排在前面”，不是“过滤掉旧论文”：每个层级的名额按 **50% / 30% / 20%** 分给 Y1 / Y2 / Y3，经典的老论文不会被挤掉。

## 2. 5 分钟快速上手

1. **在项目目录打开 AI 助手**：在项目目录里启动 Claude Code（或 Codex 等，见第 12 节）。只有在这个目录下启动，命令和规则才会生效。
2. **检索一个课题**：
   ```
   /find 小样本目标检测中的元学习方法
   ```
   AI 助手会：扩展检索词 → 检索本地 dblp（按层级/年份）+ dblp 未收录的新论文 → 逐篇看标题摘要筛选 → 入库并建分组 → 生成报告和 BibTeX。
3. **打开图形化论文库**：双击项目目录里的 `打开论文库.bat`（macOS/Linux 运行 `./start.sh`；或对 AI 助手输入 `/library`），浏览器打开 http://127.0.0.1:8765。
4. **看报告**：左侧“🗂 检索记录” → 点“报告”；或直接打开 `reports\` 下的 `.md` 文件。
5. **开始阅读**：在库里点开论文 → “下载开放获取版本”或关联本地 PDF → 需要深度分析就点“加入 AI 精读队列”，再回到 AI 助手输入 `/queue`。

> 不记得命令也没关系，在工作站目录里直接用自然语言说（“帮我找 xxx 方向近三年的论文”“把目标检测这组导出 BibTeX”），AI 助手会按工作站规则执行。

## 3. 常见工作流程（按场景）

### 3.1 针对一个课题做系统检索

```
/find <研究问题> [分组名]
```
- 分组名可写成 `大组/小组`，例如 `/find 开放词汇目标检测 目标检测/开放词汇`，检索结果会直接放进这个小组（不存在会自动创建）。
- 结果：`reports\日期_课题.md`（按层级、年份档分组，每篇附相关性理由和摘要）+ `exports\日期_课题.bib` + 库中的分组。
- 觉得不够全：直接说“再补充一下 xxx 角度”，AI 助手会追加检索并入库到同一分组。

### 3.2 追踪最新论文（dblp 还没收录的）

```
/fresh object detection
/fresh diffusion model --since 2026-06-01
```
- 覆盖：期刊“在线优先发表”文章、已开但 dblp 未收录的会议（如刚开完的会议）、OpenReview 录用论文、arXiv 上声明被优先出处录用的论文。
- AI 助手汇总后会问你要不要入库。

### 3.3 整理分类（两层分组）

典型做法：**一个课题 = 一个大组，课题下的不同角度 = 小组**。

```
目标检测-基础模型            ← 大组
 ├ 开放词汇检测              ← 小组
 ├ 小样本检测
 ├ 数据集与评测
 └ 未分小组（自动）          ← 在大组里、但还没放进任何小组的论文
```
- 在界面里：选中论文 → 顶部“加入分组…”或“移入小组…”。详见第 5.4 节“两层分组”。
- 检索时直接指定 `大组/小组`，结果会进对应小组。

### 3.4 精读与笔记

1. **拿到 PDF**（升级到 L2）
   - 开放获取的：详情面板点“下载开放获取版本”（或批量“下载开放获取 PDF”），自动从 arXiv / Unpaywall 下载。
   - 付费的：用校园网自己下载，然后
     - 把 PDF **拖进**详情面板的虚线框（复制进 `library\pdfs`），或
     - 在“本地 PDF 路径”里粘贴路径点“关联”（**只链接，不移动原文件**；勾选“复制到库内”则复制一份）。
2. **AI 精读**（升级到 L3）
   - 详情面板点“加入 AI 精读队列”（可批量）→ 回到 AI 助手输入 `/queue`。
   - AI 助手会先拿到全文（本地 PDF；没有的话自动下载开放获取版本），完整阅读后生成 Markdown 分析，存到 `library\ai_notes\<大组>\<小组>\`，并自动挂到这篇论文上。
   - 笔记格式固定为 `docs\精读笔记模板.md`：锐评（判决、新意、最强证据）→ 一句话总结 → **创新思路主线**（背景 → 问题 → Idea → 机制 → 贡献，串起全文重点）→ 核心贡献 → 问题背景 → 方法详解（每个模块写“作用”，实现一两句）→ 实验要点 → 关联笔记。不含公式推导和图表，公式一律用纯文本。想调整格式，直接改这个模板文件或告诉 AI 助手。
   - 笔记里提到的、你库里已有的论文，会顺手加上“关联”（基于/对比了/相关），可在详情面板查看或删除。
   - 也可以直接对 AI 助手说“精读库里第 12 篇”。
3. **从全文补摘要**：在线补不到摘要的论文（Elsevier 期刊、刚出版的新论文），关联 PDF 后会**自动**从全文首页提取摘要（离线、不耗 API 额度，来源显示为“本地 PDF 全文提取”）。之前就已关联 PDF 的论文：详情面板点“从 PDF 提取”，或批量 / 分组菜单里点“从 PDF 提取摘要”。
4. **我的笔记**：详情面板的“我的笔记（纯文本）”直接写，自动保存（`library\notes\<编号>.txt`）。
5. **已有的 AI 笔记文件**：在“AI 分析笔记”下粘贴 `.md` 路径点“关联”。

### 3.5 写论文时：导出引用、核验参考文献

```
/bib 目标检测-基础模型                # 导出整个大组（含其所有小组）
/bib 目标检测-基础模型/开放词汇检测    # 只导出一个小组
/bib 3,7,12                     # 按库内编号
/bib starred                    # 星标论文
/verify D:\thesis\refs.bib      # 核验参考文献（.bib 或每行一条的 .txt）
```
- BibTeX 优先使用 dblp 的规范条目（`DBLP:conf/cvpr/...`）；未正式出版的会带 `note` 字段说明。
- `/verify` 会逐条判定：✅ 已核实 / ⚠️ 有出入（标题、年份、第一作者、DOI 不一致，会给出正确值）/ ❌ 查无此文（可能是 AI 编造或极冷门），并输出一份修正后的 BibTeX。

## 4. 命令详解

> 在项目目录下启动的 Claude Code 中，输入 `/` 可看到命令列表；若看不到，重启 Claude Code。
> 用 Codex 等其他 AI 时没有斜杠命令，用自然语言说出命令名即可（如“执行 find：小样本目标检测”），见第 12 节。

| 命令 | 作用 | 产出 |
|---|---|---|
| `/find <问题> [分组]` | 完整检索 + AI 筛选 + 入库 | 报告、BibTeX、库中分组 |
| `/fresh <关键词> [--since 日期] [--under-review]` | 只查 dblp 未收录的优先出处新论文 | 列表（可选入库） |
| `/enrich <分组/编号/all> [pdf]` | 补全摘要、引用数、开放获取链接（在线查不到时自动从本地 PDF 提取摘要）；加 `pdf` 则下载开放获取 PDF | 库内论文升级到 L1/L2 |
| `/queue [数量]` | 处理图形界面里排队的 AI 任务（精读/补全/下载） | AI 分析笔记挂到论文上 |
| `/verify <文件>` | 核验参考文献 | 核验结果 + 修正 BibTeX |
| `/bib <分组/编号/starred>` | 导出 BibTeX | `exports\*.bib` |
| `/library` | 启动图形化论文库 | http://127.0.0.1:8765 |
| `/venues <出处清单>` | 配置优先出处（自动核对 dblp 键、排除 workshop、查 OpenAlex/ISSN） | 更新 `config/venues.yaml` |
| `/dblp-update` | 用下载好的数据包构建/更新本地 dblp | `data/dblp.sqlite` |

### /find 的内部流程（了解即可）

1. 把研究问题拆成 3–5 组英文检索词（同义词、缩写各一组；检索按 **标题** 匹配，自动词干化）。
2. `gather`：每组检索词 × 每个层级检索本地 dblp（按年份档配额）；前 2 组检索词再查 dblp 缺口；前 80 个候选自动补摘要（OpenAlex 按 DOI 查询，免费）。
3. AI 助手逐篇看标题+摘要判断相关性，写一句中文理由；相关论文太少会自动追加 1–2 轮检索。
4. `finalize`：入库、建分组、写报告和 BibTeX。

## 5. 图形化论文库详解

### 5.1 启动与布局

- 启动：双击 `打开论文库.bat`，或对 AI 助手说 `/library`，或命令行 `python -I ps/server.py`。
- 地址：http://127.0.0.1:8765（只有本机能访问）。关闭：关掉黑色的服务器窗口。
- 布局：**左侧**导航（文献库筛选、分组树、工具）· **中间**论文列表 · **右侧**论文详情（点标题打开，✕ 关闭）。
- 调整宽度：鼠标移到中间列表与右侧详情之间的分隔线上（光标变成 ↔），按住左右拖动即可；宽度会被记住，**双击分隔线**恢复默认宽度。
- 滚动位置：在长列表中点开一篇论文时，列表保持原位（被点的那一行停在原处）；在同一篇论文上改状态/星标/分组时，详情面板也不会跳回顶部。

### 5.2 论文列表

- 顶部：库内搜索（标题/作者/摘要，回车生效）、层级筛选、补全等级筛选（≥ L1/L2/L3）、排序（优先级 / 加入时间 / 年份 / 标题 / 出处）。“按出处”按出处名称 A→Z 排序（不分大小写），同一出处内按年份从新到旧，没有出处的排最后。
- **出处筛选（类似 Excel）**：点表头“出处 ▾”弹出筛选框，列出当前列表里的所有出处及篇数，勾选/取消勾选后点“确定”；“（全选）”一键全选/全不选；搜索框可过滤出处名，输入后**按回车 = 只显示匹配的出处**（例如输入 `T` 回车只看 TPAMI/TIP 等以 T 开头的出处）；筛选框顶部也有“按出处 A→Z 排序”。筛选生效时表头显示“▼ 已筛选”，列表上方出现黄色提示条（可“修改”或“清除筛选”），篇数显示为“显示数 / 总数”。出处筛选会与搜索、层级等其他筛选叠加；切换到其他分组/文献库视图时自动清除。表头全选和批量操作只作用于筛选后可见的论文。
- 每行：☐ 选择 · ★ 星标（点击切换）· 标题（点击打开详情）· 作者 · 发表状态标记 · 所属分组 · 出处与年份 · T/Y 徽章 · 补全等级（📄 = 有 PDF；⚠ = 关联的 PDF 文件找不到了）· 阅读状态。
- 左侧“文献库”：全部 / 星标 / 待读 / 在读 / 已读 / 已排除。

### 5.3 批量操作

勾选论文（表头复选框 = 全选当前列表）后，顶部出现批量操作栏：

| 操作 | 说明 |
|---|---|
| 设置状态… | 批量改为待读 / 在读 / 已读 / 已排除 |
| ★ 加星 / ☆ 去星 | |
| 加入分组… | 列出所有大组和小组；选“＋ 新建分组…”可输入 `大组` 或 `大组/小组` |
| 移入小组… | （仅在查看某个大组时出现）放进本大组下的某个小组，并**离开本大组的其他小组** |
| 移出本大组 / 移出本小组 | 见 5.4 规则 |
| 补全摘要 · 下载开放获取 PDF | 后台执行，完成后右下角提示并自动刷新 |
| 从 PDF 提取摘要 | 对已关联 PDF、还没有摘要的论文，从全文首页读取摘要（离线，不耗额度；已有摘要的不会被覆盖）。提取失败的会在提示里列出原因 |
| 加入 AI 精读队列 | 之后对 AI 助手输入 `/queue` |
| 导出 BibTeX | 弹窗中可复制或下载 `.bib` |
| 从库中删除 | 只删库记录，**不删除** PDF 和笔记文件 |

### 5.4 两层分组

**规则**

| 情况 | 结果 |
|---|---|
| 层级 | 只有两层：大组 → 小组。小组下不能再建小组 |
| 论文放进小组 | **自动同时属于它的大组** |
| 一篇论文 | 可以同时属于多个大组、多个小组 |
| 移出小组 | 只离开该小组，**仍在大组中**（变成“未分小组”） |
| 移出大组 | 同时离开该大组下的所有小组 |
| 移入小组 | 放进该小组，并离开同一大组下的其他小组（适合“重新归类”） |
| 删除小组 | 小组没了，论文仍在大组中 |
| 删除大组 | 其下所有小组一并删除；**论文本身永远不会因删除分组而被删除** |
| 重名 | 同一层级不能重名；不同大组可以各有同名小组（如都叫“数据集”） |
| 名称 | 不能包含 `/`（`/` 用来表示“大组/小组”路径） |

**在哪里操作**

- **左侧分组树**：点大组 = 查看大组全部论文（含各小组）；点小组 = 只看该小组；`└ 未分小组` = 大组里还没归入任何小组的论文；`▾ / ▸` 折叠展开；“＋ 新建大组”在分组标题右侧；“＋ 新建小组”在当前查看的大组下面。
- **小组切换条**：查看大组或小组时，列表上方出现 `全部 · 各小组 · 未分小组 · ＋新建小组`，一键切换。
- **分组菜单**：鼠标移到分组名上点 `⋯`：
  - 编辑：重命名、修改说明、换颜色（小组跟随大组颜色）、新建小组
  - 结构：小组可“升级为大组”或“移到另一个大组下”；没有小组的大组可“变为某个大组的小组”（含小组的大组不行，因为最多两层）。结构调整时组内论文会跟着加入新的大组，原大组中的成员关系保留。
  - 对组内全部论文：导出 BibTeX、补全摘要、从 PDF 提取摘要、下载开放获取 PDF、加入 AI 精读队列、全部标为已读
  - 删除
- **详情面板**：分组标签显示为 `大组 › 小组`，点 ✕ 移出；下拉框“＋ 加入分组 / 小组”加入任一大组或小组。

### 5.5 论文详情面板

| 区块 | 功能 |
|---|---|
| 顶部 | 层级/年份/补全等级徽章；标题、作者、出处、年份、发表状态、被引次数；DOI / arXiv / OpenReview / dblp / 开放获取链接 |
| 状态与分组 | 待读/在读/已读/已排除切换；★；分组标签与加入下拉框 |
| 摘要 | 显示来源（openalex / springer / arxiv / 本地 PDF 全文提取 / 手动编辑）；没有时点“尝试补全”（在线），有 PDF 时还可点“从 PDF 提取”（离线） |
| PDF 全文 | 有 PDF：新标签页打开 / 内嵌预览 / 取消关联（见下方说明）；显示是“库内文件”还是“链接到本地文件”。没有 PDF：下载开放获取版本 / 粘贴本地路径关联 / 拖拽上传。关联或上传后，若论文还没有摘要，或原摘要也是从（之前的）PDF 提取的，会自动从新 PDF 提取 |
| AI 分析笔记 | 点击在大窗口中渲染阅读（表格、列表、图片、公式）；加入 AI 精读队列；关联已有 .md 文件；✕ 取消关联（不删文件） |

**取消关联 PDF 会做什么**（点按钮后弹窗会逐条说明）：

1. 解除论文与该文件的关联。论文记录、你的笔记、分组、关联关系都不变。
2. 如果摘要是**从这个 PDF 提取的**（来源 = 本地 PDF 全文提取），会一并清除，因为它属于这个文件。之后关联新的 PDF 会自动从新文件重新提取。来自 OpenAlex / Springer / arXiv 或手动编辑的摘要不受影响。
3. 文件本身：**链接到本地的文件永远不会被删除或移动**。**库内副本**（library/pdfs，拖拽上传 / 勾选“复制到库内” / 下载开放获取版本得到的）默认保留，弹窗里可勾选“同时删除库内副本”。原始文件不受影响。
4. 如果这篇论文已有 AI 笔记，弹窗会提醒你：笔记若是用错误的 PDF 生成的，请取消关联笔记，换好 PDF 后重新加入精读队列。笔记不会被自动处理。

**PDF 关联错了怎么办**（例如把论文 1 的 PDF 关联给了论文 2）：在论文 2 上点“取消关联”（可勾选删除库内副本）→ 给论文 1 关联这个 PDF → 给论文 2 关联正确的 PDF。两篇论文的摘要都会按各自的新 PDF 自动重新提取。
| 我的笔记 | 纯文本，输入后约 1 秒自动保存 |
| 关联论文 | 选择库内另一篇论文 + 关系类型（改进自 / 对比了 / 基于/使用 / 同一数据集 / 观点相反 / 综述涵盖 / 相关）+ 一句说明；会显示在关系图中 |
| 来自哪些检索 | 这篇论文是哪次检索找到的，以及当时的相关性理由 |
| 补全日志 | 每次补全/下载的结果（排查用） |

### 5.6 dblp 目录检索

- 左侧“🔎 dblp 目录检索”：在本地 884 万篇中按标题检索，可限定层级和年份（如 `2021-`）。
- 完全离线，**不消耗任何 API 额度**。已在库中的论文会显示“库内 #编号”。
- 勾选 → 选分组（可选）→“加入文献库”。加入后是 L0，可再批量“补全摘要”。
- 注意：这里只有 dblp 已收录的论文；最新论文请用 `/fresh` 或 `/find`。

### 5.7 关系图

左侧“🕸 关系图”：显示有关联关系的论文网络，可按分组（大组含其小组）筛选。节点颜色 = 层级，大圆点 = 星标，连线标签 = 关系类型；点节点打开详情。

### 5.8 检索记录

每次 `/find`（以及导入）都会记录：检索问题、时间、候选数/保留数。可“查看论文”（只显示这次检索入库的论文）或“报告”。

### 5.9 AI 任务队列

界面里“加入 AI 精读队列”的任务在这里排队，可删除待处理任务。处理方式：对 AI 助手输入 `/queue`（Codex 中说“处理队列”）。没有全文（付费且未关联 PDF）的论文会标为失败并说明原因，关联 PDF 后重新加入即可。

## 6. 配置

### 6.1 优先出处：`config/venues.yaml`

项目自带的是**示例配置**：tier 1 有 CVPR、NeurIPS、ICLR（会议）和 TPAMI（期刊），tier 2 有 ECCV、TIP。**请换成你自己领域认可的出处。**

**最简单的方式**：把清单发给 AI 助手，例如
```
/venues tier 1：CVPR、ICCV、TPAMI；tier 2：WACV、Neurocomputing；删掉 NeurIPS
```
AI 助手会按 `docs/workflows/venues.md`：在本地 dblp 中核对 dblp 键 → 检查 workshop 等需要排除的出处名 → 查 OpenAlex ID / ISSN → 选择补新论文的数据源 → 写入配置 → 重新计算库中论文的层级（`library.py recompute-tiers`）。需要先建好本地 dblp（见 8.1）。

每个出处的字段含义见文件头部注释；其中 `dblp_venue_regex` 用来只认正会（排除 workshop），`fresh` 决定用哪些在线源补 dblp 缺口。

### 6.2 年份优先级

在 `venues.yaml` 的 `year_priority`：
```yaml
year_priority:
  - {from: 2024}             # Y1
  - {from: 2021, to: 2023}   # Y2
  - {to: 2020}               # Y3
```
修改后告诉 AI 助手“重新计算层级”即可更新库中已有论文。

### 6.3 API key：项目目录下的 `.env`

把 `.env.example` 复制一份改名为 `.env`，用记事本填写（`.env` 不会被提交到 git）。也可以用同名的系统环境变量。

| 变量 | 用途 | 不填会怎样 |
|---|---|---|
| `OPENALEX_API_KEY` | OpenAlex（补摘要、找 dblp 未收录的新论文）。在 https://openalex.org 免费申请 | OpenAlex 基本不可用（不带 key 的请求会被直接限流 429），新论文和摘要只能靠其他源，覆盖面明显变小 |
| `CROSSREF_MAILTO` | Crossref 礼貌池，只需填你的邮箱 | 仍可用，但更容易被限流 |
| `UNPAYWALL_EMAIL` | Unpaywall 找开放获取 PDF，只需邮箱 | 只能从 arXiv 等来源下载 PDF |
| `SPRINGER_META_API_KEY` | Springer（补 LNCS 会议摘要，如 ECCV）。在 https://dev.springernature.com 免费申请 | Springer 会议摘要补不到 |

`config/api_limits.yaml` 里还有 Scopus、IEEE、Semantic Scholar 等条目，属于预留，脚本暂未调用。

规则：**key 只写在 `.env` 里，不要发到 AI 对话中**。填好后告诉 AI 助手“测试一下 key 能不能用”。

### 6.4 用量限制：`config/api_limits.yaml`

- 每个 API 有官方限额（`official`）和工作站执行上限（`limit_*`，**你可以改**）。工作站所有脚本都会遵守，并记账在 `data/usage.sqlite`。
- 查看今日/近 7 天用量：让 AI 助手运行 `python -I ps/netlib.py`，或直接问“今天 API 用了多少”。
- 主要额度：OpenAlex 每天 $1 免费（关键词搜索 $0.001/次，按 DOI 查单篇免费），Crossref 每秒 3 次，Springer 每天约 500 次，arXiv 每 3 秒 1 次。
- 遇到限流会自动等待重试一次；遇到人机验证会**立即停用该数据源**，不会重试或绕过。

## 7. 数据存放位置与备份

| 位置 | 内容 |
|---|---|
| `library\library.sqlite` | **个人文献库**（论文、分组、关联、检索记录、队列）——最重要 |
| `library\pdfs\` | 库内管理的 PDF（关联的外部 PDF 留在原处） |
| `library\ai_notes\` | AI 分析笔记（Markdown） |
| `library\notes\` | 你的纯文本笔记（`编号.txt`） |
| `reports\` · `exports\` | 检索报告 · BibTeX |
| `data\dblp.sqlite` | 本地 dblp（8 GB，可随时重建） |
| `data\dblp\` | dblp 原始数据包 |
| `data\runs\` | 检索/补新的候选池（JSON）。**入库后自动删除**（检索记录、报告和 BibTeX 会保留）；从未入库的 7 天后自动过期 |
| `data\tmp\` | 临时中间数据（精读时的 PDF 全文与页面渲染、筛选理由、粘贴的参考文献等）。**任务结束即自动清除** |
| `data\usage.sqlite` | API 用量账本 |
| `data\backups\` | 自动/手动备份 |
| `config\` | 出处、用量限制等配置 |

**中间数据自动清理**（默认开启，无需手动操作）：
- `/queue` 每完成（或失败）一个任务，删除该任务的临时目录；命令结束时再清空 `data\tmp\`。
- `/find` 入库后删除候选池和筛选理由文件；`/fresh` 的结果入库后删除候选池。
- PDF 下载中途失败不会留下 `.part` 残片。
- 启动图形界面时会顺带清理 24 小时前遗留的临时文件（比如中途被打断的任务）。
- 想看还剩什么：让 AI 助手运行 `python -I ps/scratch.py status`；手动清空：`python -I ps\scratch.py clean`。

**备份**：复制整个 `library\` 文件夹即可（建议先关闭图形界面）。外部关联的 PDF 不在其中，需要自己保管原文件。
**清空文献库**（例如删除测试数据）：关闭界面后删除 `library\library.sqlite`、`library.sqlite-wal`、`library.sqlite-shm`，下次启动会自动建新库；或者直接让 AI 助手帮你清理。

## 8. 维护

### 8.1 更新本地 dblp（建议每月一次）

1. 下载（二选一）：
   - 月度稳定版（**快**，推荐）：https://drops.dagstuhl.de/entities/collection/10.4230/dblp.xml → 最新一期的 `dblp-YYYY-MM-DD.xml.gz` 和 `.md5`
   - 每日版（新但慢，须当天下完）：https://dblp.org/xml/dblp.xml.gz 和 `dblp.xml.gz.md5`
2. 放到项目目录的 `data\dblp\`（**与 `dblp.dtd` 同一文件夹**，dtd 已随项目提供，不要删）。
3. 告诉 AI 助手 `/dblp-update`（或“更新 dblp”）。或自己运行（约 9 分钟，建议先关闭图形界面）：
   ```
   python -I ps\dblp_build.py --dump data\dblp\<文件名>.xml.gz --db data\dblp.sqlite
   ```
   新库先写到临时文件，成功后才替换旧库，中途失败不影响现有数据。文献库不受影响。

### 8.2 升级工作站本身

- 用 git 获取的：在项目目录运行 `git pull`。你的数据（`library/`、`data/`、`reports/`、`exports/`、`.env`）都被 `.gitignore` 排除，不受影响。
- 下载压缩包的：解压新版本，**只覆盖** `ps/`、`web/`、`docs/`、`.claude/`、`AGENTS.md`、`CLAUDE.md`；不要覆盖 `library/`、`data/`、`.env`，`config/` 里的文件你改过的话也不要覆盖。
- 升级后如果提示缺少 Python 包，运行 `python -m pip install -r requirements.txt`。

## 9. 命令行脚本参考（进阶）

> 一般不需要手动运行，AI 助手会代劳。所有脚本都用 `python -I ps\<脚本>.py` 运行，加 `-h` 查看完整帮助。

**本地 dblp**
```
python -I ps/dblp_query.py search "semi-supervised segmentation" --tier 1 --year 2021-
python -I ps/dblp_query.py venue "Pattern Analysis"       # 查出处的 dblp 键
python -I ps/dblp_query.py bib conf/cvpr/HeZRS16           # dblp 规范 BibTeX
python -I ps/dblp_query.py stats                           # 数据版本
```
**dblp 缺口 / 检索**
```
python -I ps/fresh.py "object detection" --since 2026-01-01
python -I ps/search.py gather --q "..." --q "..."          # /find 第一步
python -I ps/search.py finalize <run.json> --keep 1,3,5 --reasons r.json --group "大组/小组"
```
**文献库**
```
python -I ps/library.py list --group "大组" [--unassigned]
python -I ps/library.py add conf/cvpr/HeZRS16 --group "大组/小组"
python -I ps/library.py group list | create | rename | delete | add | remove | move | reparent
python -I ps/library.py attach-pdf <编号> "D:\papers\x.pdf" [--copy]   # 关联后自动（重新）从 PDF 提取摘要
python -I ps/library.py detach-pdf <编号> [--delete-copy]   # 取消关联；PDF 来源的摘要一并清除
python -I ps/library.py link-note <编号> <笔记.md>   |   scan-notes
python -I ps/library.py bib --group "大组/小组" -o exports/x.bib
python -I ps/library.py stats
```
**补全 / 核验 / 用量**
```
python -I ps/enrich.py meta --group "大组" | pdf --ids 1,2

python -I ps/pdfabstract.py <file.pdf>                            # 测试单个 PDF 能提取出什么
python -I ps/pdfread.py text <编号> --task queue-<任务号>           # 精读准备：全文与页面渲染 → data/tmp（临时）
python -I ps/pdfread.py figures <编号> --out <笔记目录>/assets --prefix <方法名>   # 精读笔记用图（保留）

python -I ps/verify.py refs.bib --out exports/verified.bib
```

## 10. 常见问题与排错

| 现象 | 原因与处理 |
|---|---|
| 浏览器打不开 127.0.0.1:8765 | 服务没启动：双击 `打开论文库.bat` 或 `/library`；黑色服务器窗口不要关 |
| 双击 bat 后提示端口被占用 | 服务已经在运行（可能是 AI 助手启动的），直接用浏览器打开即可 |
| 输入 `/find` 没反应 | 确认 Claude Code 是在项目目录启动的；必要时重启。Codex 等没有斜杠命令，用自然语言说（见第 12 节） |
| 提示 `dblp.sqlite not found` | 还没建本地 dblp：见 8.1 |
| 提示 `No module named ...` | 缺 Python 包：`python -m pip install -r requirements.txt` |
| 论文一直是 L0，补不到摘要 | 多为 Elsevier 期刊（如 Pattern Recognition）：Elsevier 不开放摘要。关联 PDF 后会自动从全文提取摘要 |
| “从 PDF 提取摘要”失败 | 提示里会写原因：扫描版 PDF（没有文字层）、首两页找不到 Abstract 标题、版式特殊导致结果过短/过长。可在详情面板手动粘贴摘要，或让 AI 助手看一下 |
| 下载不到 PDF | 只有开放获取版本能自动下载；付费论文请自己下载后拖入或关联路径 |
| PDF 显示 ⚠（文件找不到） | 关联的外部 PDF 被移动或删除；重新关联新位置 |
| AI 笔记没有自动挂到论文上 | 笔记里需包含该论文的 arXiv 链接、DOI 或完整标题；或在详情面板手动“关联” |
| 检索提示某个数据源被停用 | 触发了限流或人机验证，工作站自动停用以保护账号；稍后再试或换天 |
| NeurIPS 当年论文找不到 | NeurIPS 正会论文在开会前后才在 OpenReview 公开，在此之前只能找到 arXiv 声明录用的 |
| 新论文找到了但 dblp 里没有 | 正常：dblp 更新滞后。这类论文来自 OpenAlex/Crossref/OpenReview/arXiv，更新 dblp 后会自动匹配 |
| 想撤销误操作 | 分组删除不会删论文；论文删除不会删 PDF/笔记。重要操作前可复制 `library\` 备份 |

## 11. 已知限制

- **dblp 时效**：本地库与数据包同步（每月更新一次即可），最新论文由在线源补充。
- **检索按标题匹配**：本地 dblp 没有摘要，所以检索词要贴近论文标题里会出现的词；`/find` 会用多组同义检索词弥补。
- **摘要缺口**：Elsevier 期刊摘要在线不可得（有 PDF 时可从全文提取）；Springer LNCS 会议（如 ECCV）通过 Springer API 补。
- **从 PDF 提取摘要**：按首两页的版式规则提取，已在 IEEE（含首页脚注）、Elsevier 版式上验证；扫描版 PDF 无法提取。
- **OpenReview**：只能用检索接口（按 ID 查询会触发人机验证）；审稿中论文默认不检索。
- **Scopus、IEEE、Semantic Scholar**：配置中预留，脚本尚未接入。
- **公式**：默认不渲染（见 5.11）。
- **分组最多两层**。
